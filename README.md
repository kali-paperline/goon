# GOON

a cli program to help gooner disk. created with python 3.13

## FEATURES

- reformat photo, gif, and video to some format
- resize photo, gif, and video to a specific resolution
- rename photo, gif, and video to a sorted integer name
- make a photobook from photo list

## REQUIREMENTS

- pillow
- ffmpeg-python

## INSTALLATION & RUN

get program with git

```cmd
git clone "https://github.com/kali-paperline/goon.git"
cd goon
```

install the requirements

```cmd
pip install ffmpeg-python pillow
```

run program with python

```cmd
python goon.py
```
